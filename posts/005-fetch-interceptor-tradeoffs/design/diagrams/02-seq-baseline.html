Sequência · cenário S1 · token expirado nos dois MFEs

Baseline: cada MFE renova o próprio token

O que acontece

Os dois MFEs enxergam o token expirado ao mesmo tempo e cada um chama refreshToken com o mesmo refresh token. Com rotação ligada, só o primeiro vale: o segundo recebe 401, limpa o storage compartilhado e o usuário é deslogado.

Cenários afetados

  • S1 concorrência: 2 refreshes no servidor
  • S5 multi-aba: mesmo efeito entre abas
  • S2 não se aplica: não há patch para carregar
